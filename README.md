# LJT-Homepage

This repository contains the personal academic homepage of **Junteng Liu**, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and hosted on GitHub Pages.

* First-year Ph.D. candidate at the HKUST NLP Group, Hong Kong University of Science and Technology (HKUST), supervised by Professor Junxian He
* B.Eng. from Shanghai Jiao Tong University (SJTU), 2020 -- 2024
* Research interests: LLM reasoning and reinforcement learning, hallucination in vision-language models (VLM), LLM truthfulness and interpretability

The site content lives in [_pages/about.md](_pages/about.md) (front page), [_publications/](_publications) (publication entries) and [_pages/cv.md](_pages/cv.md), while site-wide settings are in [_config.yml](_config.yml).
